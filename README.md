# Ignasi's Agent Skills

Free, tested skills for Claude Code (SKILL.md standard, also works in Codex CLI, Cursor and Gemini CLI).
212 more skills, and Pro versions with scripts and CI, are on **[Agensi](https://www.agensi.io)**.

## Install
```
/plugin marketplace add ignasisant/ignasi-agent-skills
/plugin install <skill-name>@ignasi-agent-skills
```
