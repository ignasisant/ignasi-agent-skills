# Claude Plugin Packager

Package skills, commands, subagents, hooks and MCP servers into a Claude Code plugin + marketplace, then validate and test-install it.

## Install
```
/plugin marketplace add ignasisant/ignasi-agent-skills
/plugin install claude-plugin-packager@ignasi-agent-skills
```
Or use it with no install from Agensi: [Claude Plugin Packager on Agensi](https://www.agensi.io/skills/claude-plugin-packager-ship-skills-as-a-plugin).
