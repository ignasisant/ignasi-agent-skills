# Prompt Eval Harness

Build an eval suite for any system prompt, skill or agent: realistic and adversarial cases, code + LLM-judge graders, multi-model runs with cost and latency, regression checks.

## Install
```
/plugin marketplace add ignasisant/ignasi-agent-skills
/plugin install prompt-eval-harness@ignasi-agent-skills
```
Or use it with no install from Agensi: [Prompt Eval Harness on Agensi](https://www.agensi.io/skills/prompt-eval-harness-test-prompts-skills-agents).
