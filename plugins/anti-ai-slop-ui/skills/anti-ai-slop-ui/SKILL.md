# Anti AI-Slop UI

## 1. Audit
Look for the usual tells and list each one found:
- Purple-to-blue gradients and glow effects.
- One default font for everything.
- Emoji or generic icon rows as features.
- Three identical cards in a row; centered hero with two buttons.
- Same radius and shadow everywhere.
- Invented stats and testimonials.

## 2. Pick one direction
Choose one: editorial, brutalist, industrial, soft-organic or retro-technical. State why it fits the product.

## 3. Define tokens
- Type: one display face and one text face, with a size scale.
- Color: 5 colors, text contrast at least 4.5:1.
- Spacing scale and one radius rule.

## 4. Redesign
Start with the hero or main screen, then apply tokens everywhere.

## 5. Check
Empty, loading and error states; dark mode; 375px mobile; visible focus rings; reduced motion.

Output a findings table (issue, fix) and the changed code.
