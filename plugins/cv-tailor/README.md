# CV Tailor

Tailor your resume and cover letter to each job for ATS keyword match and metric-driven impact, without inventing experience.

## Install
```
/plugin marketplace add ignasisant/ignasi-agent-skills
/plugin install cv-tailor@ignasi-agent-skills
```
Or use it with no install from Agensi: [CV Tailor on Agensi](https://www.agensi.io/skills/cv-tailor-ats-ready-resume-cover-letter-per-job).
